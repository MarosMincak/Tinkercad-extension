TINKERCOMPLETE · PRIVACY

Your code stays in your browser.

Effective October 13, 2026 · Version 0.1.0

What the extension reads

TinkerComplete reads the Arduino code in the active Tinkercad Circuits text editor to calculate suggestions. This processing happens locally in the page. Code is not sent to the developer or any external service, and the extension does not save your code separately.

What is stored

Your enabled state, automatic suggestion preference, typing delay, and character threshold are saved using Chrome's local extension storage. They are not synced or transmitted by this extension.

No collection or tracking

The extension has no analytics, telemetry, advertising, AI service, account system, or remote library downloads. It does not collect personal information or browsing history.

Permissions and references

Access to www.tinkercad.com lets the extension find the editor as you navigate within Tinkercad. Storage permission saves your preferences. The extension requests no access to other websites.

Reference links open an external documentation site only when clicked. Those websites have their own privacy practices. Tinkercad's own storage, networking, and privacy practices remain separate from this extension.

Contact

Questions or bug reports: GitHub issue tracker. Avoid posting private code or student information in public issues.
