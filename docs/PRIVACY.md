# TinkerComplete Privacy Policy

Effective October 13, 2026. Applies to version 0.1.0.

TinkerComplete reads code in the active Tinkercad Circuits Arduino text editor solely to generate suggestions locally. It does not transmit code to its developer, an AI provider, or any other external service. It does not persist a separate copy of the sketch.

Only these preferences are saved in Chrome's local extension storage: enabled state, automatic suggestions, typing delay, and minimum character threshold. The extension does not sync them.

There is no analytics, telemetry, advertising, account system, remote library download, or personal-data collection. TinkerComplete does not read browsing history.

The extension requests access to `www.tinkercad.com` to attach to the editor during navigation within Tinkercad, and `storage` permission to save preferences. It does not request access to other websites.

Clicking a documentation link opens its external website. Those websites and Tinkercad have separate privacy practices. The extension does not change Tinkercad's own saving or networking.

Contact: [GitHub issue tracker](https://github.com/MarosMincak/Tinkercad-extension/issues). Do not include private code or student information in public reports.

This is an independent extension, not affiliated with or endorsed by Autodesk, Tinkercad, or Arduino.
